# LexiForge Exercises

Standalone English–Polish vocabulary practice with 31 supplied phrases, five exercise types and Mixed practice.

No ChatGPT or LexiForge sign-in is required by this app. Vocabulary is saved separately in each visitor's browser, with JSON/CSV import and export. Pronunciation uses the device's English speech voices. There are no API keys or paid AI calls.

## Publish on GitHub Pages
1. Create a new repository, such as lexiforge-exercises. On GitHub Free it must be public.
2. Upload all files in this folder to the repository root, including index.html and the JavaScript/CSS files.
3. In Settings > Pages, choose Deploy from a branch.
4. Choose main and /(root), then Save.
5. Open the GitHub Pages URL shown in Settings > Pages after deployment.

The Windows LexiForge repository does not need to be made public or merged into main.

## Vocabulary
All 31 supplied everyday phrases are included. Add/edit/import your own list from My vocabulary. Export before clearing browser data. Lists are not synchronized across devices or visitors.

## Audio
An English voice must be available in the browser/operating system. Use Pronunciation settings to choose accent and speed. Audio requires user interaction and may be limited by browser settings.

## Local use
Serve this folder using any static HTTP server. Opening index.html directly as a file may block JavaScript modules.
